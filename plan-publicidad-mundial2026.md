## PASO 0 — Define el precio ANTES de publicar (urgente)

El mundial arranca el **11 de junio**. Sin precio y link de pago, todo el contenido de abajo no convierte.

**Recomendación para mercado peruano:**

| Opción | Monto | Cuándo usar |
|---|---|---|
| Pago único "temporada completa" | S/ 15–25 | Si quieres volumen rápido |
| Pago único "premium" | S/ 30–50 | Si el modelo es claramente diferenciado |
| Acceso gratuito + lista VIP pagada | S/ 0 entrada / S/ 10 VIP | Para captar leads primero |

**Método de cobro sugerido:**
- Yape o Plin (fricción mínima para peruanos)
- Link de pago Mercado Pago o PayU como respaldo
- Confirmar acceso manual vía WhatsApp o activación en Supabase admin

**Acción inmediata:** Definir precio → crear Yape/Plin con QR → tener el QR listo para los reels.

## NOTAS FINALES

1. **El tiempo corre**: el mundial empieza el 11 de junio. La ventana de venta más caliente son los 5 días antes.
2. **No inventar datos en los reels**: solo mencionar cifras si las tienes (ej. precio, número de partidos = 104 es correcto).
3. **Una sola acción por reel**: siempre "link en bio" o "escríbeme". Nunca mezclar dos CTAs.
4. **Precio primero**: sin precio definido, los reels generan curiosidad pero no convierten. Definirlo antes de publicar el Reel 1.
5. **Los reels no necesitan cara a cámara**: screen recordings del producto con voz en off funcionan igual de bien para este tipo de contenido.
